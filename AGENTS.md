# tabpfn-rel — agent notes

## Treat this repo as public

This repository is private for now and will become public soon. Apply these
rules to all work now, including history that will become public.

Code, docs, and results are intended for publication under Apache-2.0.
Nothing may reference Prior Labs-internal infrastructure, systems, names,
or paths. Keep internal deliberation, unreleased plans or results,
customer or partner names, and internal tracker IDs out of published content.
This applies to everything pushed to the remote: code, comments, docstrings,
commit messages, branch names, and PR text.

Write for readers who only have access to this repository. Before the first
push, rename any branch that contains an internal tracker ID. Check the
diff, commit messages, branch name, and PR text for internal information
before publishing.
